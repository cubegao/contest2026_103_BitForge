# ADR-0004：vendor 适配层与最小 NSH 配置

- 状态：已采纳
- 日期：2026-09-06

## 1. 背景与目标

比赛要求交付物集中在专属仓 `contest2026_103_BitForge`。需要设计 vendor 层的目录结构，并给出"最小 NSH"的内核配置——目标：编译出固件、真机启动到 `nsh>` 提示符、单根 USB 线完成烧录与终端。

## 2. 适配流程

1. **目录结构**（`board/esp32p4-function-ev-board/`）
   - `configs/nsh/defconfig`：唯一配置事实来源；
   - `scripts/Make.defs`：Make 路径的工具链/链接脚本设置 + HAL 版本 pin（见 ADR-0003）；
   - `README.md`：板级说明。

2. **manifest 映射**（`contest2026_103_BitForge.xml`）
   - `<linkfile src="board/esp32p4-function-ev-board" dest="vendor/espressif/boards/esp32p4/esp32p4-function-ev-board"/>`——`repo sync` 后专属仓的板级目录自动出现在 openvela 构建树的标准 vendor 位置；当前工作区同步手工建立软链以便开发；
   - 删除模板占位 `board/contest_board/` 与未使用的 app/quickapp 链接。

3. **defconfig 设计**（最小 NSH 集合）
   - 架构与芯片：`CONFIG_ARCH="risc-v"`、`CONFIG_ARCH_CHIP_ESP32P4=y`；
   - 板级选择：`CONFIG_ARCH_BOARD_CUSTOM=y` + `CONFIG_ARCH_BOARD_CUSTOM_DIR="boards/risc-v/esp32p4/esp32p4-function-ev-board"`（NuttX 标准树外板机制，vendor 配置 ↔ 树内板级源码的衔接点，见 ADR-0001 的分层）；
   - 控制台：`CONFIG_ESPRESSIF_USBSERIAL=y`（USB-Serial-JTAG），显式关闭 UART0 控制台；
   - 内存：`CONFIG_ESPRESSIF_SPIRAM=y`（32MB PSRAM @200MHz HEX）+ `CONFIG_MM_REGIONS=2`（PSRAM 注册为第二堆区域）+ `CONFIG_ESPRESSIF_SPIRAM_IGNORE_NOTFOUND=y`（PSRAM 异常时不阻塞启动，便于问题隔离）；
   - NSH 基础：`CONFIG_SYSTEM_NSH`、`CONFIG_NSH_BUILTIN_APPS`、`CONFIG_NSH_READLINE`、`CONFIG_INIT_ENTRYPOINT="nsh_main"`；
   - 初始化：`CONFIG_BOARD_LATE_INITIALIZE=y`（板级外设初始化入口）+ `CONFIG_NSH_ARCHINIT=y`；
   - 可观测性：`CONFIG_RAMLOG` + `CONFIG_RAMLOG_SYSLOG`（dmesg）、`CONFIG_DEBUG_FEATURES/WARN/ERROR`、`CONFIG_FS_PROCFS`；
   - flash：`CONFIG_ESPRESSIF_FLASH_16M=y`。

## 3. 关键决策

- **PSRAM 在最小 NSH 阶段即启用**：显示适配（第二阶段）的帧缓冲必须放在 PSRAM（双缓冲共 2.4MB，超出 SRAM 容量），尽早暴露 PSRAM 链路问题，避免问题堆积到显示阶段；
- **defconfig 显式写出关键项**（而非依赖默认值）：构建可复现、配置意图自文档化；
- **配置排布遵循 savedefconfig 字母序**：与 NuttX 配置管理习惯一致，diff 干净。

## 4. 验证方式

```bash
./build_esp32p4.sh          # 封装 build.sh vendor/.../configs/nsh --cmake
esptool --chip esp32p4 elf2image -fs 16MB -fm dio -ff 80m \
    --ram-only-header -o nuttx.bin nuttx
esptool -c esp32p4 -p /dev/ttyACM0 -b 921600 write-flash 0x2000 nuttx.bin
```

真机结果：`nsh>` 提示符正常；`uname -a` 显示 `risc-v esp32p4-function-ev-board`；`free` 显示 34,004,200 字节总堆；`ps` 正常。
