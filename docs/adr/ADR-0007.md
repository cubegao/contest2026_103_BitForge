# ADR-0007：GT911 触摸驱动（轮询模式与确认帧策略）

- 状态：已采纳
- 日期：2026-09-12

## 1. 背景与目标

目标板显示屏子板集成 Goodix GT911 电容触摸控制器，通过 I2C0（GPIO7=SDA、GPIO8=SCL）连接主控，地址 0x5D。面板的 INT 线未接到 ESP32-P4。目标：为 NuttX 输入框架交付 `/dev/input0` 字符设备，使触摸坐标可被上层（NSH hexdump、后续图形栈）消费。

## 2. 适配流程

### 2.1 板级层（esp32p4_touch.c）

- **模拟中断源**：由于 INT 线未接，板级层提供一个"假中断"钩子集
  （`gt9xx_board_s`：irq_attach / irq_enable / set_power），用 20ms 周期的
  看门狗反复触发驱动的 ISR——与真实 GPIO 中断同上下文。驱动的 ISR 只做
  置位 + poll 通知，开销可忽略。
- **set_power 为 no-op**：触摸控制器与显示同电源域，显示链路上电后即常供。

### 2.2 驱动数据路径（gt9xx.c 重构）

核心变化：**I2C 流量全部收归一个 20ms 周期的 HPWORK 轮询工作项**
（`gt9xx_poll_work`），应用层的 `read()` 只拷贝已解码样本，永不阻塞在总线上。

每周期流程：

1. 读状态寄存器 0x814E（1 字节）；
2. bit7=1 且点数 1..5：读点数据（0x814F 起 8 字节：track/xL/xH/yL/yH/size/保留）；
3. 解码坐标（支持 Kconfig 配置的 X/Y 镜像，适配面板装配方向）；
4. **确认帧**：写 0x814E=0 清除缓冲状态——不清除则控制器不再上报后续帧；
5. 发布样本到缓存并 poll 通知等待者。

关键防护语义（实测经验）：

- **确认帧每周期至多一次**：对确认写做背靠背重试会把控制器打入
  "所有写被拒、读正常"的状态，只能断电恢复（三个独立实现均观察到）。
- **bit7=0 时也要确认**：与厂商驱动一致，该写在无帧时无害。
- **未确认帧追踪**：一次确认失败的坐标被记录，控制器重报该帧时不再当作新触摸。

### 2.3 I2C 可靠性

- **NACK 重试**：控制器在内部 MCU 刷新坐标缓冲期间会短暂 NACK 访问；
  每次失败传输重试 `CONFIG_INPUT_GT9XX_I2C_RETRIES` 次（默认 5），
  间隔 5ms。
- **写事务长度**：本 I2C 主控拒绝 3 字节数据写（指针+值），确认帧采用
  4 字节单事务（指针 + 状态清零 + track 字节清零），已验证可靠。
- **双地址探测**：控制器复位释放时按 INT 电平锁存地址（0x5D 或 0x14）；
  主地址静默时自动尝试互补地址（`CONFIG_INPUT_GT9XX_ALT_ADDR`）。
- **ioctl 支持**：实现 `TSIOC_GETMAXPOINTS`（返回 1），否则输入框架
  无法分配样本缓冲、输入设备创建失败（见 ISSUE-003 的教训）。

### 2.4 Kconfig

`INPUT_GT9XX`（select SCHED_HPWORK）、`INPUT_GT9XX_I2C_RETRIES`、
`INPUT_GT9XX_ALT_ADDR`、`INPUT_GT9XX_X_INVERT[_MAX]`、
`INPUT_GT9XX_Y_INVERT[_MAX]`、`INPUT_GT9XX_I2C_FREQUENCY`。

## 3. 关键决策

| 决策 | 选择 | 理由 |
|------|------|------|
| 触发方式 | 看门狗模拟中断（板级） | INT 未接；与厂商 BSP 的轮询模式一致 |
| I2C 流量归属 | HPWORK 轮询工作项独占 | 应用 read() 零阻塞；总线竞争由 trylock 串行化 |
| 确认帧策略 | 每帧一次、永不重试 | 重试会打桩控制器（实测三方一致） |
| 坐标变换 | Kconfig 镜像开关 | 面板装配方向与显示不一致，驱动层修正 |

## 4. 验证方式

NSH 下后台 `hexdump /dev/input0 &` 持续采样，手指触摸时样本从
`npoints=0` 变为有效帧：

```
0000: 01 00 00 00 00 19 6d 01 b0 00 00 00
      npoints=1  id=0  flags=0x19(DOWN|ID|POS)  x=365  y=432
```

坐标随触点实时变化、松手后回到 npoints=0，确认识别链路完整。
