# ADR-0006：MIPI-DSI 显示适配

- 状态：已采纳
- 日期：2026-09-06

## 1. 背景与目标

目标板配备 7 英寸 1024×600 MIPI-DSI 屏（面板桥接芯片 EK79007）。目标：内核内建立完整的显示管线，暴露 `/dev/fb0`，并带有可视化的上电自检。

## 2. 显示管线结构

```
DPI framebuffer (PSRAM, ×2 双缓冲)
        │  DW-GDMA 链表传输
        ▼
DSI bridge FIFO ──► DSI host (video mode) ──► DSI PHY ──► EK79007 面板
```

## 3. 适配流程

1. **芯片层 DSI 驱动**（`arch/risc-v/src/esp32p4/esp_mipi_dsi.c`）
   - 上电时序：PHY 供电由外部 LDO 通道承担（通过 PMU 寄存器直接配置 2.5V 输出）→ PHY PLL 锁定 → 数据 lane 进入停止态；
   - 面板复位（GPIO27，低有效，复位后按数据手册要求等待 ≥100ms 才能发命令）与背光使能（GPIO26）；
   - **DCS 初始化命令必须在 LP（escape）模式发送**——EK79007 不接受高速模式下的初始化命令，否则 Sleep Out 不执行、面板保持黑屏（对应寄存器 `CMD_MODE_CFG` = 0x010F7F02）；
   - DPI 视频时序编程（48MHz 像素时钟、源时钟 240MHz）；
   - 双缓冲管理：两个连续 PSRAM 缓冲（各 1228800 字节），显式前缓冲翻转；
   - **上电自检**：初始化完成后把可见缓冲填红并启动红/蓝交替线程——不依赖任何应用即可目视确认整条链路（PHY → host → bridge → DMA → 面板）。

2. **DMA 通道管理**（`arch/risc-v/src/esp32p4/esp_dw_gdma_idf.c`）
   - DesignWare GDMA 通道分配、链表描述符管理、中断注册；帧缓冲数据经 DMA 写入 DSI bridge FIFO（地址窗口 `0x50105000`，GDMA 主端口按地址路由到桥而非 DRAM）。

3. **IDF→NuttX 兼容层**（`arch/risc-v/src/esp32p4/esp_idf_shim.h`）
   - 厂商 HAL 头文件按 ESP-IDF 运行时编写（日志宏、错误检查宏、heap_caps 分配、FreeRTOS 延时/自旋锁）；shim 把这些原语映射到 NuttX 等价物（syslog、内核堆 + 64 字节对齐、usleep、spinlock），使移植的驱动零改动编译。

4. **板级 fb 设备**（`boards/.../src/esp32p4_fb0_stub.c`）
   - 在 DSI 驱动 API 之上注册 `/dev/fb0`：RGB565、1024×600、双缓冲（`fblen=2457600`）；有双缓冲时通过 pan 显示翻页，无撕裂。

5. **构建接线**
   - Kconfig：`CONFIG_ESP32P4_MIPI_DSI`（Make 与 CMake 双路径条件编译）；
   - defconfig：`CONFIG_ESP32P4_MIPI_DSI=y` + `CONFIG_DRIVERS_VIDEO=y` + `CONFIG_VIDEO_FB=y`。

## 4. 关键决策

- **芯片层/板级分层**：DSI 硬件控制归芯片层；`/dev/fb0` 字符设备归板级——芯片层不接触 NuttX 设备模型；
- **自检内建在驱动里**：显示问题排查成本高，开机红屏/红蓝交替是最直接的"链路通"判据，黑屏排障第一步永远是看 boot log 的 DSI 初始化日志（ramlog/dmesg）；
- **复位/背光 GPIO 直写寄存器**：GPIO27/GPIO26 通过 IO MUX + GPIO 寄存器直接驱动，不依赖 GPIO 驱动框架，避免初始化顺序依赖。

## 5. 验证方式

真机记录（dmesg）：

```
[DSI] === MIPI-DSI init START ===
[DSI] PHY PLL locked (timeout remaining=99845)
Framebuffers: count=2 contiguous=1 [0]=0x48000040 [1]=0x4812c040 size=1228800 (filled RED)
FB: /dev/fb0 registered (1024x600 16bpp, double buffered, base=0x48000040 fblen=2457600)
[DSI] Re-sending Sleep Out + Display On...
[DSI] Starting DMA linked-list...
[DSI] Linked-list DMA refresh started
[DSI] Demo thread started (pid=2)
```

`ls /dev` 出现 `fb0`；屏幕出现红/红蓝交替自检画面（待目视最终确认）。
