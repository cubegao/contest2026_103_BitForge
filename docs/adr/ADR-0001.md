# ADR-0001：ESP32-P4 芯片层移植

- 状态：已采纳
- 日期：2026-09-06

## 1. 背景与目标

工作区 nuttx（openvela 分支）尚无 ESP32-P4（双核 RV32IMAC @400MHz）支持。本阶段目标：把芯片层带入 nuttx，使内核能针对 `ARCH_CHIP_ESP32P4` 完成配置与编译。这是后续一切适配的地基。

## 2. 适配流程

芯片层移植按以下顺序执行，每一步形成一个独立 commit，保证可回溯、可整理为公共仓 PR：

1. **架构头文件**（`arch/risc-v/include/esp32p4/`）
   - `chip.h`：外设寄存器基地址与地址映射；
   - `irq.h`：中断向量号到 NuttX IRQ 的映射表；
   - `gpio_sig_map.h`：GPIO 信号矩阵（外设信号到引脚的映射表）。
   同时在 `arch/risc-v/Kconfig` 注册 `ARCH_CHIP_ESP32P4`（选择 RV32 ISA、多核、最小中断向量表等架构能力）。

2. **芯片层基础**（`arch/risc-v/src/esp32p4/`）
   - `esp_chip_rev.c`：通过 eFuse 读取芯片版本，导出支持的版本区间；
   - `hal_esp32p4.mk` / `hal_esp32p4.cmake`：声明该芯片需要的 esp-hal-3rdparty 头文件搜索路径与 HAL 源文件清单（Make 与 CMake 双通道）；
   - `Kconfig`：芯片版本选择（rev <3.0 与 ≥3.0 布局差异）、L2 Cache 大小/行宽选择、MSPI 规避开关；
   - `Make.defs` / `CMakeLists.txt`：芯片目录的构建接线。

3. **共享 espressif 层同步**（`arch/risc-v/src/common/espressif/`）
   - ESP32 系芯片（c3/c6/h2/p4）共用一套核心代码：启动、时钟树、eFuse、Cache、PSRAM、串口、中断。P4 的加入要求把共享层同步到支持 P4 的水位；
   - 同步内容包括：`esp_start.c` 等核心文件中的 P4 条件分支、HAL 胶水（定时器、ADC、加密、EMAC、GPTIMER 等）、CMake 接线（`CMakeLists.txt`、`Bootloader.cmake`、`Wireless.cmake/mk`）；
   - 同步 `arch/risc-v/src/common/` 的构建文件：`riscv_mtimer.c` 仅在 `CONFIG_ONESHOT` 下编译（P4 使用自己的时钟源），工具链定义同步（栈保护级别、ELF 入口点等）。

4. **构建工具**（`tools/espressif/`）
   - `Config.mk`：导出 `ARCH_SRCDIR`、HAL 仓库名；读取 flash 频率配置；**P4 的第二阶段加载偏移为 0x2000**（区别于 C3/C6/H2 的 0x0）；32MB flash 支持；
   - 新增 CMake 侧镜像生成与烧录目标（mkimage、flash、esptool 胶水、chip_info）；
   - 顶层 `CMakeLists.txt`：多链接脚本支持（逐脚本预处理）。

5. **内核修正**（随移植需要的最小集）
   - `include/nuttx/debug.h`：兼容 shim，把上游头文件位置 `<nuttx/debug.h>` 路由到 openvela 的 `<debug.h>`；
   - `sched/task/task_init.c`：`nxtask_init()` 容忍 NULL 属性参数（HAL 胶水可能以默认属性创建任务）；
   - `riscv_mdelay.c` / `riscv_udelay.c`：忙等函数放入 `.iram1`，保证 PSRAM/MPU 区域重配置期间仍可执行。

## 3. 关键决策

- **文件按模块分 commit**，而不是一次性合入全部内容——评审友好、问题定位可以二分到 commit；
- **只带最小集**：摄像头（MIPI-CSI）、JPEG 编码器、触摸（GT911）等与本阶段目标无关的文件不进构建体系，减少首版风险面；
- **共享层同步以"支持 P4 所需"为界**，不带入无关重构。

## 4. 验证方式

- 构建系统可以为 `ARCH_CHIP_ESP32P4` 完成 Kconfig 配置与全量编译；
- 既有芯片（esp32c6）的配置不受共享层同步影响。

## 5. 产物

nuttx `feat/openvela-esp32p4` 分支上的 5 个 commit：
`feat(arch): add ESP32-P4 chip headers and Kconfig` → `feat(arch): add ESP32-P4 chip layer base` → `feat(arch): sync espressif common layer for ESP32-P4` → `feat(tools): add espressif image and flash build support` → `feat(kernel): core updates required by the ESP32-P4 port`。
